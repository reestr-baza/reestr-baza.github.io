# Реестр — база товаров в браузере

Таблица как в Excel для базы товаров: фото в ячейках, формулы (СУММ, ЕСЛИ, ВПР, СУММЕСЛИ, ОКРУГЛ…), фильтры и сортировка, форматы ₽ / ¥ / $, скрытие строк и столбцов, карточка товара с сеткой фото и текста, импорт и экспорт Excel, резервные копии.

## Запуск

```bash
npm install
npm run dev      # разработка
npm test         # тесты движка формул
npm run build    # сборка в dist/
```

Данные демо-версии хранятся в браузере (IndexedDB). Серверная версия с входом по паролю и хранением фото — следующий этап.
